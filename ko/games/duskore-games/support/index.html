Duskore Games — 게임 지원

출시 전 지원

Duskore Games는 개발 중입니다. 이 페이지는 App Store 승인이나 TestFlight 배포 완료를 뜻하지 않습니다. 문의 시 게임명, 정확한 버전·빌드, 기기, OS, 재현 방법을 알려주세요. 공개 GitHub 이슈에 비밀번호·토큰·이메일·개인 화면을 올리지 마세요.

라이브러리와 플레이

로그인 후 라이브러리에서 게임을 골라 PLAY를 누르세요. HOME은 현재 판을 종료하고 해당 게임 메뉴로, MORE GAMES는 통합 라이브러리로 돌아갑니다. 설정은 플레이 화면을 덮지 않고 메뉴에서 제공합니다. 규칙·기기 내 진행·음악은 게임마다 구분됩니다.

코인과 광고

게임마다 하루 플레이 코인 5개를 제공하며 새 판에 1개를 사용합니다. 광고가 허용되고 제공 가능한 경우 선택형 보상 광고 완료 후 해당 게임의 코인 1개를 받습니다. 하단 배너만 추가로 사용하며 전면 광고는 없습니다. 광고가 없으면 보상이 임의로 지급되지 않습니다. 추적을 거부해도 보유 코인으로 플레이할 수 있습니다.

계정과 데이터

게스트·Google·Apple 로그인은 하나의 컬렉션 계정으로 사용합니다. 게스트도 익명 Firebase 계정을 만듭니다. 설정에서 로그아웃과 Delete Account를 제공합니다. 삭제 대상은 컬렉션 계정과 기기 내 게임 데이터이며 기존 개별 앱이나 Apple·Google 계정은 아닙니다. 성공 후 제공자 로그인을 자동으로 열지 않고 로그인 화면으로 돌아갑니다. 기기 내 정리 실패가 표시되면 로컬 삭제 완료로 간주하지 말고 지원을 요청하세요. 앱 제거·로그아웃만으로 서버 계정은 삭제되지 않습니다.

사운드·점수·개인정보

공용 설정으로 배경음악과 효과음을 조절하며 라이브러리는 무음, 게임은 전용 음악을 사용합니다. 지원되는 Game Center 순위표에는 별도 공유 동의와 Game Center 인증이 필요합니다. 그 외 점수는 기기에 저장됩니다. PRIVACY CHOICES에서 제공되는 지역별 광고 선택을 확인하고 추적 권한은 iOS 설정에서 변경하세요. 새 빌드의 실기기 검증은 이 안내와 별개입니다.
