Duskore Games — 개인정보처리방침

범위와 날짜

2026년 10월 17일 갱신. 출시 준비 중인 Duskore Games iOS 컬렉션(com.duskore.games)과 내장 게임 9개에 적용됩니다. 기존 개별 앱은 계정·데이터·방침이 별도입니다. 지원 웹사이트에는 앱 분석·광고 스크립트가 없고 GitHub 호스팅·공개 이슈 방침도 적용됩니다.

계정과 기기 내 정보

Firebase Authentication과 Google·Apple 로그인은 계정 식별자와 제공자 정보를 처리하며 허가에 따라 이메일·이름·프로필을 제공받을 수 있습니다. 게스트는 익명 Firebase 계정을 사용합니다. 즐겨찾기·최근 게임·점수·플레이 코인·게임 상태·설정은 기기에 저장합니다. 코인은 구매 상품이나 금전 가치가 있는 통화가 아닙니다. 기존 개별 앱 계정·저장 데이터는 자동 이전하지 않으며 클라우드 저장 복원을 보장하지 않습니다.

점수와 공유

Hexa Merge·Star Jumper·Stack and Pop·2048은 Game Center 인증과 명시적 점수 공유 동의 후 Apple Game Center를 사용할 수 있습니다. 제출 점수와 Game Center 플레이어 정보에는 Apple 서비스 규칙이 적용됩니다. 공유 거부 시 점수를 전송하지 않습니다. 다른 게임 점수는 기기에 저장합니다. Firebase 컬렉션 계정 삭제는 Apple Game Center 계정 삭제가 아니며 이미 제출된 Game Center 기록까지 반드시 지우지는 않습니다.

분석과 진단

Firebase Analytics는 앱·게임 이벤트, 설치 식별자, 기기·OS·앱 정보, 언어와 대략적 지역을 처리할 수 있습니다. Crashlytics는 충돌 정보, 설치 식별자와 기기·OS·앱 정보를 처리할 수 있습니다. Analytics의 광고 저장·광고 사용자 데이터·광고 개인화는 별도로 기본 거부되며 AdMob 동의로 활성화되지 않습니다.

광고와 선택

Google AdMob·UMP를 통해 하단 배너와 선택형 보상 광고를 제공합니다. 현재 구현은 iOS 추적 권한과 지역별 동의 상태 확인 후 광고를 요청합니다. 광고 파트너는 기기·광고 식별자, 대략적 위치, 광고 상호작용과 진단 정보를 처리할 수 있으며 해당 허가가 있는 경우 다른 회사의 앱·웹사이트 정보와 결합해 측정·개인화할 수 있습니다. 지역별 선택에는 현지법상 판매·공유로 보는 처리가 포함될 수 있습니다. 추적을 거부해도 보유 코인으로 플레이할 수 있고 PRIVACY CHOICES·iOS 설정에서 가능한 선택을 다시 확인할 수 있습니다.

보관과 삭제

Settings - Delete Account는 Firebase 계정 삭제와 아직 열지 않은 게임을 포함한 컬렉션 로컬 데이터 정리를 요청하며 Apple 경로는 승인 철회를 포함합니다. 인증 취소·오류는 성공이 아닙니다. 로컬 저장 실패 시 추가 정리와 지원이 필요할 수 있습니다. 로그아웃·앱 제거만으로 서버 계정은 삭제되지 않습니다. 분석·진단·광고·Game Center 기록은 제공자 보관 정책과 법적 의무를 따르며 삭제한 Firebase 계정과 직접 연결되지 않을 수 있습니다. 기존 개별 앱이나 Apple·Google 계정까지 삭제되는 것은 아닙니다.

제공자와 문의

Firebase Authentication·Analytics·Crashlytics, Google·Apple 로그인, Apple Game Center, AdMob·UMP와 공개된 광고 파트너, 공개 지원의 GitHub를 사용합니다. 제공자는 보호 조치에 따라 해외에서 정보를 처리할 수 있습니다. 어린이를 특정 대상으로 하지 않는 일반 이용자용 컬렉션입니다. 개인정보 문의 시 계정 식별 정보를 공개하지 마세요. 공개 이슈는 작성자·GitHub·관리자가 삭제할 때까지 남습니다. 중요한 변경은 방침 날짜를 갱신합니다.
