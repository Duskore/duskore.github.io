개인정보를 수집하지 않습니다

앱에는 계정·로그인·광고·분석·충돌 보고·네트워크 요청이 없습니다. 개인정보를 수집하거나 사용자를 추적하지 않습니다.

기기 안에 저장하는 데이터

진행 상황·설정과 판정 기록은 기기 안 앱 저장 공간에만 기록됩니다. 판정 기록은 날짜·물건·도장·걸린 시간 등의 플레이 기록 CSV입니다. 이 파일은 어디로도 보내지 않습니다. 클라우드 백업은 없으며 앱을 삭제하면 기기 내 데이터도 지워집니다.

라이선스 링크

크레딧의 라이선스 링크는 사용자가 누를 때만 시스템 브라우저로 엽니다. 연결된 웹사이트에는 해당 사이트의 방침이 적용됩니다.

지원 웹사이트

이 지원 웹사이트에는 분석·광고 스크립트가 없습니다. GitHub 호스팅과 공개 지원 이슈는 GitHub 방침을 따릅니다. 공개 이슈의 내용은 다른 사람도 볼 수 있으므로 개인정보를 게시하지 마세요.

이용 대상과 문의

어린이를 특정 대상으로 하지 않는 일반 이용자용 게임입니다. 개인정보 관련 문의는 개인정보를 공개하지 않고 지원 링크를 이용해 주세요. 중요한 방침 변경은 위 날짜를 갱신해 알립니다.
