Same Day Appraiser support

This page supports the Korean-language iPhone and iPad game during release preparation. It does not announce availability or App Store approval.

How to play

Sit at the appraisal desk and compare each customer’s object with its catalog record. Rotate the object, use the loupe, scale and measuring mat, and tap it to hear its sound. Stamp SAME if every detail matches, or DIFFERENT if any detail differs. One wrong judgment makes the same day repeat. Finish seven days to complete a week; replay finished days from the calendar.

Saving

Progress and settings are saved only in the app’s storage on your device. There is no cloud backup. Deleting the app deletes these saves and local judgment records.

Accessibility

Open Options in the office for color-vision modes, 150% text size, reduced motion and captions.

Report a problem

Use the public GitHub issue link below. Include the game name, exact version/build, device, OS version and steps to reproduce the problem. Do not post personal information, credentials or private files. Review screenshots before attaching them.
