Duskore Games — Game support

Prerelease support

Duskore Games is in development. These pages do not announce App Store approval or TestFlight availability. For help, include the game name, exact app version/build, device, OS and steps. Public GitHub issues must not contain passwords, tokens, email addresses or private screenshots.

Library and play

Sign in, choose a game from the library and tap PLAY. HOME ends the current run and returns to that game's menu. MORE GAMES returns to the collection library. Settings are available from menus, not over the playing area. Each game retains its own rules, local progress and music.

Coins and advertising

Each game provides five daily play coins; starting a run uses one. When permitted and available, completing an optional rewarded ad grants one coin for that game. Bottom banners may appear; no interstitial ads are used. If an ad is unavailable no reward is fabricated. Declining tracking does not block playing with available coins.

Account and data

Guest, Google and Apple sign-in share one collection account. Guest also creates an anonymous Firebase account. Settings provides sign-out and Delete Account. Deletion applies to the collection account and its local game data, not accounts in standalone apps or your Apple/Google account. Successful deletion returns to login without starting provider sign-in automatically. If local cleanup reports a failure, do not assume deletion of local data has finished; contact support. Uninstalling or signing out does not delete the server account.

Sound, scores and privacy

Shared controls manage music and effects; the library is silent and each game has its own track. Supported Game Center leaderboards require separate sharing permission and Game Center authentication. Other scores stay local. PRIVACY CHOICES revisits available regional ad choices; tracking permission is managed in iOS Settings. New-build device validation is separate from these instructions.
